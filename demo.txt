================================================================================
  AGENTIC AI BOT — DEMO WALKTHROUGH
================================================================================

This document is a step-by-step terminal guide. Every curl command can be
copy-pasted as-is. All calls run in mock mode — no real API keys required.

────────────────────────────────────────────────────────────────────────────────
  SETUP (one-time)
────────────────────────────────────────────────────────────────────────────────

  # 1. Install dependencies
  export PATH="$HOME/.local/bin:$PATH"
  poetry install

  # 2. Copy example environment file
  cp .env.example .env
  # No API keys required — the system is 100% rule-based (zero LLM calls).

  # 3. Start the server
  poetry run uvicorn app.main:app --reload

  # 4. Verify it's up
  curl http://localhost:8000/health
  # → {"status":"healthy","version":"0.1.0","uptime_seconds":...}

  curl http://localhost:8000/health/ready
  # → {"status":"ready","sheets_available":false,"memory_sessions":0}
  # sheets_available=false is expected when GOOGLE_SHEETS_URL is not set.

────────────────────────────────────────────────
  S005 — Low Confidence → Human Review Required
────────────────────────────────────────────────

  Parent: Jennifer Patel (P005)
  What happens: Transcript is ambiguous — only 1-2 fields extracted. Score < 0.75.
                Graph calls interrupt(). Session is PAUSED and added to review queue.

  # Step 1: Trigger the scenario (it will block / pause)
  curl -s -X POST http://localhost:8000/api/v1/outreach/scenario/S005/run \
    | python3 -m json.tool

  Expected:
  {
    "outreach_status": "human_review",
    "requires_human_review": true,
    "review_id": "rev_...",
    "confidence_score": 0.25,
    "captured_data": {
      "captured_email": null,
      "captured_mobile": "+1-555-0505",
      "captured_school": null,
      "captured_weekday": null,
      "captured_time": null
    }
  }

  Note the review_id from the response.

  # Step 2: Check the pending review queue
  curl -s http://localhost:8000/api/v1/review/pending | python3 -m json.tool
  # → Array of review items with session_id, reason, context_snapshot

  # Step 3: Resolve the review — operator fills in the missing fields
  # Replace REVIEW_ID with the value from the Step 1 response
  curl -s -X POST http://localhost:8000/api/v1/review/REVIEW_ID/resolve \
    -H "Content-Type: application/json" \
    -d '{
      "decision": "edit",
      "edited_data": {
        "captured_email": "jennifer.patel@example.com",
        "captured_school": "Maplewood Academy",
        "captured_weekday": "Wednesday",
        "captured_time": "4:00 PM"
      }
    }' | python3 -m json.tool

  Expected after resolve:
  {
    "status": "resumed",
    "outreach_status": "completed",
    "confidence_score": 1.0
  }
  # The graph resumes from where it paused and writes the corrected data to Sheets.

────────────────────────────────────────────────────────────────────────────────
  CONNECTING REAL GOOGLE SHEETS
────────────────────────────────────────────────────────────────────────────────

  1. Create a Google Service Account and download credentials.json
  2. Share the target spreadsheet with the service account email (Editor role)
  3. Edit your .env file:

     GOOGLE_SHEETS_URL=https://docs.google.com/spreadsheets/d/YOUR_SHEET_ID/edit
     GOOGLE_SHEETS_CREDENTIALS_JSON=./credentials.json

  4. Restart the server. On first write the app auto-creates four tabs:
       Parents | Students | AuditLog | HumanReview

  No migrations. No schema files. The header row IS the schema.


────────────────────────────────────────────────────────────────────────────────
  ADDING A NEW TELEGRAM USE CASE (3 lines of code)
────────────────────────────────────────────────────────────────────────────────

  Only one file needs to change: app/agents/telegram/templates.py

  1. Add your template to the TEMPLATES dict:
       "progress_update": "Hi {student_name}, great progress in {course_name}! "
                          "Your streak is {attendance_streak} sessions. Keep it up!"

  2. Add required variables to REQUIRED_VARS:
       "progress_update": ["student_name", "course_name", "attendance_streak"]

  3. That's it. No routing changes, no new nodes, no new endpoints.

  curl -s -X POST http://localhost:8000/api/v1/telegram/send \
    -H "Content-Type: application/json" \
    -d '{"student_id": "ST006", "use_case": "progress_update"}' \
    | python3 -m json.tool
